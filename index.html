QUICK START

四步完成部署

安装向导会检测环境、创建数据表并生成配置文件，全程在浏览器完成。

上传并解压

把压缩包解压到站点目录，例如 /var/www/files 或宝塔的网站根目录。

授权目录

确保程序目录与 storage 可写，Linux 下一般设为 755 / 775。

访问并安装

浏览器打开域名，自动进入安装向导，填写数据库与管理员信息。

登录使用

安装完成后登录，即可上传与管理文件；管理员可进入后台。

终端 · 快速部署示例
# 1. 解压到站点目录
unzip 文件服务系统1.0.zip -d /var/www/sakura

# 2. 确保存储目录可写（Linux）
chmod -R 775 /var/www/sakura/storage

# 3. 本地快速体验（需已安装 PHP 8+）
cd /var/www/sakura && php -S 127.0.0.1:8000

# 4. 浏览器访问
http://127.0.0.1:8000/
FAQ

常见问题

部署与使用中容易遇到的几个问题，先看这里。

必须要有 MySQL 吗？

1.0 版本使用 MySQL 保存用户、设置与操作日志，需要 PHP 的 PDO MySQL 扩展。安装向导会自动创建数据库与数据表，无需手动导入 SQL。若数据库已存在，填好库名即可。

上传大文件失败怎么办？

上传大小受 PHP 配置限制。可调整 upload_max_filesize、post_max_size 与 max_execution_time，Nginx 还需同步调整 client_max_body_size，重启 PHP / Web 服务后生效。

普通用户能看到别人的文件吗？

不能。普通用户登录后，根目录被限定为自己的账号文件夹，路径解析做了越界防护；管理员的根目录是站点根目录，可在后台按用户查看与管理文件。

忘记管理员密码怎么办？

删除项目下的 install.lock，重新访问 install.php，在向导第三步用同一账号重设密码即可，数据库配置会保留，无需重新填写。

如何关闭注册入口？

管理员进入后台 → 设置 → 关闭「注册开关」。关闭后登录页不再显示注册按钮，注册接口也会拒绝请求；已有账号不受影响。

手机上可以正常使用吗？

可以。布局针对手机做了单独适配：侧栏抽屉、文件网格、长按进入多选、底部批量操作栏，触屏下也能完成复制、移动、删除与预览。

如何更换文件根目录？

管理员后台 → 设置 → 文件根目录，填写服务器上的绝对路径并保存（要求目录存在且 PHP 可读写）。普通用户仍被限制在各自账号目录中。
